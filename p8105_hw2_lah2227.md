My steps for cleaning:

1.  `clean_names` to make all column names snake case.

2.  `pivot_longer` since the route columns were unnecessarily separated.
    I added a prefix “route” so only the number of the route was
    retained. Those numbers were then places into `route_number`. Values
    of each of these columns were sent to `route_name`, and then
    transformed to characters due to their mixed numeric and character
    nature.

3.  I did the suggested `case_match` step from instructions to create a
    logical assignment in the `entry` variable. I then realized that
    `vending` was also a chr variable and switched it to logical
    instead.

4.  I made route numbers numeric using `as.numeric`.

5.  I selected for the requested variables.
